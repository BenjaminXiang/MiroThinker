# 后台管理台 + 登录（2026-09-17）

> 关联 OpenSpec change：`add-admin-auth-and-console`（英文，代理侧门禁）。
> 状态：**计划已冻结**（2026-09-17 访谈逐项确认，14 条共识）；执行进展见同名 `-log.md`。

## 1. 为什么要做

- 现役 18188 的管理面（配置、密钥、数据浏览、访问日志、任务、上传、种子）**没有应用级认证**：
  唯一的门是部署环境里的 dbg21 nginx basic auth（只覆盖部分路径）加 iptables 白名单。
  **甲方单机部署没有这层代理**——按现状交付＝交付一个裸奔的管理台。
- 2026-09-17 访谈裁定：系统必须**自带登录**，唯一管理入口 `/main`，账号由管理员在页面维护、
  初始管理员直接播种进数据库；`/chat` 对公众保持开放。
- 同次访谈把 `/review` 人工评审台判为**过度设计**（无读者：现役入口从未挂载、无进程在跑、
  250KB 代码；几万条数据人工评审不可行）——"看数据"的需求由既有 `/browse` 承接。

## 2. 共识清单（14 条，冻结）

| # | 决策 | 要点 |
|---|---|---|
| 1 | 认证层 | 应用内唯一认证；管理面全覆盖；不依赖外部代理 |
| 2 | 账号模型 | 多账号、单一角色（都是管理员）；管理员在页面增删账号/重置密码；预留 `role` 列 |
| 3 | 存储 | 独立 SQLite `admin-auth.sqlite3`（服务期状态目录，env 可覆盖）；scrypt 加盐哈希，明文永不落库 |
| 4 | 初始管理员 | 安装/首启随机生成口令：终端打印一次 + 写 0600 文件；建议但不强制改密 |
| 5 | 会话 | HMAC 签名 Cookie（HttpOnly/SameSite=Lax；HTTPS 才带 Secure）；载荷含密码代次 → 改密/删号即踢；绝对 12h / 空闲 1h；无会话表 |
| 6 | `/main` | 未登录=登录表单，登录后=仪表盘（同 URL）；首页四块：状态卡 + 快捷入口 + 账号区 + 右上角用户/退出 |
| 7 | 门禁范围 | 6 个管理页（admin/logs/browse/jobs/upload/seeds）+ 全部 `/api/canonical-v2/*` 管理 API；页面未登录 302→`/main`，API 401 |
| 8 | 公开面 | `/chat`、`/api/chat*`、`/static/*` 保持公开、零变化 |
| 9 | 身份/留痕 | 门禁路由身份=登录用户名；彻底忽略 `X-Remote-User`（伪造无效）；公开路由记 anonymous |
| 10 | 数据页 | 用 `/browse`（浏览+任意字段子串检索+facet+导出）；跨域搜索列为候选不进本轮 |
| 11 | `/review` 退役 | 管理面侧整体删除（页面/API/服务/测试/18189 引用）；构建侧 human-review 校验家族另走 schema 切片 |
| 12 | 安全基线 | SameSite+Origin/Sec-Fetch-Site 校验写操作（无 CSRF token）；登录限流 5 次锁 1 分钟+指数退避；口令≥8；不内置 TLS（交付文档写明加 HTTPS 终止建议）；登录/登出/账号操作全审计 |
| 13 | 上线/验收 | OpenSpec change 开发 → scratch 冒烟 → 一次重启切 18188 → `install.sh` 增加播种步骤；7 条可演示验收线 |
| 14 | 回滚 | 单一命令文件切回+重启；账号库/审计独立存放，回滚不丢数据 |

## 3. 本轮不做

跨域统一搜索；检索分词/相关排序（R13）；质量指标接首页；应用内 TLS；
`/review` 构建侧校验的删除（另切片，动冻结 live-schema pin）。

## 4. 验收线（切 18188 后逐条演示）

A1 未登录拦截（页面 302 / API 401）｜A2 锁 5 次+审计+登录进台｜A3 登出/改密/删号即失效｜
A4 账号管理端到端｜A5 伪造 `X-Remote-User` 无效（operator 仍记登录名）｜A6 `/chat` 公开面零变化
（replay 门 7/7）｜A7 回滚演练（切回命令文件+重启，账号库/审计不丢）。
