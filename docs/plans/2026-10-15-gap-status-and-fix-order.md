## 4. 执行片定义（执行契约）

### 片② 别名直通＋立足点（第一优先）
- 现状：分流由 `_infer_domains()`（领域词/后缀）与 `_has_local_scope_foothold()`（立足点）决定——位于 `canonical_v2/knowledge_serving_isolated.py`（**封印包内**）；「国先中心（深圳）」这类名字形状不被词法抽取器识别 → 无立足点 → 整轮 Web-only（第 47 轮）。
- 三步：① 立足点扩展（问句命中库内实体名/别名即给立足点——真正的名字形状决策，非加词表）；② 查询期别名解析（短名/商号 → canonical id 的可维护别名表）；③ 本地兜底（web 0 条且库内有同名实体 → 回落本地作答）。
- 验收口径（第 47 轮已定）：4 种说法（全名/短名/简称/带领域词）答案均含官方要点、不得答成大湾区/合肥机构；replay 门 7/7；召回门 0 fail。
- 技术约束：改动在封印包内 ⇒ 需重封（可用轻量路径 `s12g/reseal_serving_pack.py`：逐字拷贝 + 只改 manifest，省 33.7 分钟信封校验）；双线各自切包；回滚＝保留当前包逐字节。
- 首件产物：OpenSpec change + 验证契约；RED＝第 47 轮失败两例（web 0 条误答 / 只走 web）。

### 片①min 合成层最小片
- 现状：`max_web_results` 读取窗口与答题规范（清单题 ≤12 条、不要穷尽）把长清单压短（第 42 轮定性）。窗口字段在 **封印包内**（`knowledge_serving_isolated.py`，`max_web_results` ≤ 20；枚举问句已有 `_ENUMERATION_CANDIDATE_WINDOW=128` 机制可延伸）；答题规范落点待确认（chat/提示层）。
