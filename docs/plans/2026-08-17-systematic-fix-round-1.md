## 三、逐组验收线（冻结）

每组由重放工具断言固化，要点：
- G1：答案**首句主体**=国际先进技术应用推进中心；禁河套标题/微众银行。
- G2 T1：禁"未找到关于/暂无公开的详细运营信息"，须含机构名（全称或简称）；T2 不澄清且围绕该机构。
- G3：人称追问→澄清或人域答案；禁文章标题、"这一机构名称"、微众银行。
- G4：禁"国家知识产权局/PatSnap/Incopat/未找到"（数据版 v2 落地后加"须列专利清单"）。
- G5：禁微众银行；须含优必选/越疆/乐聚/众擎/机器人域公司。
- G6：真新会话必须澄清（已过；P7 剩余工作=会话范围产品决策+UI 主体披露）。
- G7：**3 次重复全部**含优必选（稳定性线，非平均线）。
- 全局：无 error 事件、有 answer+done。

## 四、阶段计划与顺序（十阶段，两线并行）

代码线: P1 观测(1d) → P2 话术(1.5d) → P3 主题层v2(3d) →[R1热更新]→ P5 抓正文(2d) →[R2]→ P6 理解层(4d,带闸门) → P7 融合/UI+P9前端收敛(2d) → P8 总验收(1d)
