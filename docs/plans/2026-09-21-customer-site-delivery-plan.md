## 1. 交付范围

**含**：`/chat` 问答（本地知识库优先 + 网络补全）、五个管理页（`/main` 登录、`/admin` 配置、`/logs` 审计、`/browse` 浏览、`/jobs`、`/seeds`、`/upload`）、运行期数据（访问日志 / 更正 / 手工召回道），以及运维所需的启动、验收、回退脚本。

**不含**（本次明确的边界）：重建流水线的现场运行（构建在我们侧执行，见 §8）、增量（单域）更新、多租户与配额计费、对外门户/域名证书本身的申请。

**与"代码 + 数据库搬过去拉起来就行"的四处差异**（现场工作量容易被低估的地方）：

1. **数据面不只是数据库**：服务真正读取的是两个**路径冻结**的目录——服务包 4.4 GB + 索引根 2.6 GB；它们不是"随便放的 sqlite"，路径必须与打包环境逐字符一致（§4）。
2. **代码树不能直接搬 `.venv`**：editable 安装的指针是绝对路径，现场必须 `uv sync` 重建（需外网到 PyPI）。
3. **首启前必须预建两个目录**：状态目录（不存在则只有一行 warning、管理面直接不可用：无账号）与门禁根目录下的 `s12a/`。
4. **运行期依赖三类外部服务**：我方模型服务（嵌入 / 重排 / LLM）、Bocha/Serper、网页抓取目标。缺一个不会崩，但会降级——§3 的探针负责在首启前就把这件事查出来。

## 4. 路径契约（为什么必须"同构"）

迁移的核心约束不是"别改路径"，而是**三处冻结**：

1. 服务包 `manifest.json` 里记着 `index_root` 的绝对路径；
2. 索引根的 marker 里也记着 `root`；
3. serving bundle 里**逐字符**比对第 1、2 项与 CLI 传入值。

⇒ 目标机上这三者必须逐字符一致；否则只能重新封印（41 分钟 + 需搬 7.8 GB 构建信封），代价远超收益。

**必须同构的路径（服务期真正会被 stat/读取的）**：

| 路径 | 用途 | 现场形态 |
|---|---|---|
| `/var/tmp/mirothinker-data-v2/serving-pack-run16-readerbound/` | 服务包 | 实体文件 |
| `/var/tmp/mirothinker-data-v2/index-v3-v2/` | 索引根 | 实体文件 |
| `/var/tmp/mirothinker-canonical-v2-s12f/` | 状态目录（账号库/会话密钥/首启口令/访问日志/更正） | **目录必须先存在**；不存在时只有一行 warning，管理面直接不可用 |
| `/var/tmp/mirothinker-data-v2/manual-recall-v1` | 手工召回道 | 空目录即可 |
| `<data-rebuild 树>/…/s12a/` | 门禁根目录：`s12a/` 必须存在，且 `--envelope-output` 必须等于 `<gate-root>/s12a/complete-candidate-build-envelope.json` | **空目录即可**（信封文件服务期从不打开） |
| **发布 bundle 副本里的 `envelope_path`** | 与上面那条路径**逐字符比对**，启动前必须处理 | 两条路：**(a) 把这串路径在目标机/镜像里建出来**（容器形态天然满足）；**(b) 改 bundle 副本的 `envelope_path` + 重算 `content_sha256` + 同步 `--recorded-serving-bundle-sha256` + 刷新 `checksums.sha256`**。**这是现场最容易漏的一步** |
| 命令文件里其余路径 | 解析期要求存在（`--source-manifest`、`--candidate-staging-root`、`--recorded-decision-bundle` 只要求"是互不相同的字符串"） | 随 85→11 清理大幅减少（P0-6）；未清理则用空目录/空文件占位 |
| **端口** | runner 只认 `18188`，除非通过 `s12e` 包装脚本启动 | 现场换端口必须走包装脚本，否则起不来 |

> **已实跑验证（2026-09-21 演练）**：按现场步骤（scratch 代码根 + scratch 状态目录 + 端口 18299）完整拉起——`uv sync --frozen` 7.9 s（强制冷缓存，247 包）、启动 **291.0 s**、RSS 17.3 GiB、
> 冒烟「优必选科技有哪些专利」首字 **1.64 s**、12 条本地专利引用、无 error、replay 门 **G1–G7 全 PASS**（19 轮 / 4 m 59 s）、`preflight.sh` **53 PASS / 0 FAIL / 3 WARN**。
> 明细：`.agents/runs/delivery-kit-rehearsal/verification.md`。

## 6. 验收标准（分层，逐条留证）

| 层 | 判定 | 命令/方式 |
|---|---|---|
| 启动 | systemd active；日志无 release/integrity 错误；boot ≤ 5 min | `systemctl --user status`；日志相位 |
| 检索回归 | **replay 门 7/7**（G1–G7） | `cd apps/admin-console && uv run python scripts/replay_fix_round1.py --base-url http://127.0.0.1:18188 --out-dir /tmp/accept` |
| 功能抽样 | 点名 / 语义 / 关系 各一问，本地引用齐全 | `/chat` 人工 + 引用卡 |
| 性能 | TTFT：三例均 **≤30 s**（目标 ≤20 s） | 浏览器/日志时间戳 |
| 管理面 | `/main` 登录、改密、审计、`/admin` 保存+连测、`/browse`、`/logs` 可用 | 逐页 200/302 + 操作一次 |

## 7. 回退方案（三级）

1. **换包回退**：命令文件里 `--serving-pack` 指回旧包 + 重启（291 s；旧包与旧命令文件原样保留）；
2. **配置回退**：`/admin` 改回上一版配置（点"待重启"后重启生效）；
3. **整体停服**：`systemctl --user stop canonical-v2-backend`，对外由反代摘除。

首启若硬失败，日志会点名是 pack / index root / bundle / 门禁目录哪一项——不需要猜。

## 9. 风险与处置

| 风险 | 触发条件 | 处置 |
|---|---|---|
| 内存不足 | 机器 <64 GB | 提规格；或按最小并发配置（需实测，不承诺） |
| 路径不一致 | 现场未按 §4 同构 | 启动即 fail-closed 并点名；按 `site-paths.txt` 补齐（空目录即可） |
| 嵌入端点不可用/不匹配 | 网络或模型不对 | F1 降级（服务不挂）+ F2 身份探针（页面拦截） |
| 出网受限 | 甲方防火墙 | 白名单（LLM 域名、Bocha/Serper、嵌入端点）；代理无效需透明代理 |
| venv 重建失败 | 现场无外网 | 打包时附离线 wheel 缓存；或提前在我方机器演练 |
| 网页抓取降级 | 缺 Chromium | `preflight.sh` 检查；缺失时告知（抓取质量下降但不崩） |
| 切包停机超预期 | 磁盘慢 | 验收演练一次，实测耗时计入 runbook |
| 密钥泄露 | 明文入库/入 git | 只走加密渠道 + 0600 + `preflight.sh` 校验；日志不含明文 |
