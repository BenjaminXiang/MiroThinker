## ADDED Requirements

### Requirement: Professor summary is visible before opening detail
The professor admin surface MUST expose cleaned profile summaries from the list view as well as from the detail workbench, so operators can evaluate summary quality across multiple professors without opening every record.

#### Scenario: Operator reviews summaries at list scale
- **WHEN** an operator opens the professor list
- **THEN** the operator can inspect professor profile-summary text directly in the list
- **AND** opening a professor detail still shows the cleaned summary in the workbench
